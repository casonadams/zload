Engineered for Raw Speed

Designed from first principles to eliminate the physical bottlenecks of shell startup.

⚡️
Memory-Mapped Wordcode
Concatenates and byte-compiles all plugins into a single bundle.zsh.zwc. Sourcing one memory-mapped file replaces dozens of individual disk reads.
🚫
Zero Subprocess Forks
100% pure Zsh builtins and parameter expansion in the critical interactive path. Zero calls to git, sed, grep, or subshell forks $(...).
🪄
Automatic Canonical Ordering
Completions before compinit, themes before plugins, syntax-highlighting before autosuggestions. No matter what order you declare, zload sorts safely.
⏳
Lazy Tab Compinit
Defers compinit until your first <Tab> press. Early compdef calls are automatically buffered and replayed, saving 40–100ms at startup.
🎯
Command Proxy Stubs
Stub heavy CLI tools like nvm, pyenv, or kubectl via --on. Startup latency is 0ms until the command is invoked.
📦
Seamless OMZ & Prezto
Load omz:git or prezto:utility without 100MB framework clones. Automatically injects missing lib/git.zsh and theme colors.
🗂
Smart PATH & FPATH
Deduplicates $PATH and $fpath, expands ~, verifies directory existence, and auto-links ~/.zfunc for custom completions.
🔒
Reproducible Lockfiles
Freeze exact Git commit hashes with zload lock and sync across machines with zload sync for 100% deterministic dotfiles.

Human-First Configuration

Choose a tab below to see how easy your ~/.zshrc looks with zload.

~/.zshrc (Standard Setup) 
# 1. Bootstrap zload (auto-clones on fresh machines)
if [ ! -d "${HOME}/.zload" ]; then
  git clone --depth 1 https://github.com/casonadams/zload.git "${HOME}/.zload"
fi
source "${HOME}/.zload/zload.zsh"

# 2. Deduplicating path management in clean array syntax
user_paths=(
  ~/bin
  ~/.local/bin
  /opt/homebrew/bin
)
zload path "${user_paths[@]}"

# 3. Declare plugins
plugins=(
  omz:lib/completion.zsh
  zsh-users/zsh-completions
  omz:git
  omz:extract
  casonadams/walh-shell
  lukechilds/zsh-nvm --on nvm,node,npm
  zsh-users/zsh-syntax-highlighting --defer
  zsh-users/zsh-autosuggestions
)
zload "${plugins[@]}"
bindkey '^ ' autosuggest-accept

# 4. Lazy completion initialization
zload compinit --lazy

💡 Prompt Recommendation: Pair with a high-performance prompt like Powerlevel10k (zload romkatv/powerlevel10k) or Starship (zload eval starship "starship init zsh") to complement zload's sub-millisecond shell startup.

Smart PATH & FPATH Helpers 
# Prepend to PATH: native array syntax with existence check and deduplication
user_paths=(
  ~/.opencode/bin
  ~/.cargo/bin
  ~/.local/bin
  /opt/homebrew/bin
  /opt/homebrew/sbin
  /opt/homebrew/opt/openjdk/bin
  /usr/local/bin
)
zload path "${user_paths[@]}"

# Prepend to fpath with deduplication
zload fpath ~/.my-completions /opt/homebrew/share/zsh/site-functions

# Automatic ~/.zfunc discovery:
# If ~/.zfunc exists (uv, bwc, pipx completions), zload automatically
